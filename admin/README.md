# Arghya Trust Admin Frontend

## Local development

1. Install dependencies:
`npm i`
2. Set API URL in `.env`:
`VITE_API_BASE_URL=http://localhost:5000`
3. Start frontend:
`npm run dev`

## Production build

1. Build:
`npm run build`

Production build is configured with base path `/admin/` so it can be served from:
`https://your-domain.com/admin`
